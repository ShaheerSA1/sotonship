# Event overview

SotonShip 2026. Friday 16 to Sunday 18 October 2026, Barclays Eagle Labs Southampton. All times BST.
Website: https://live.sotonship.space (team page, schedule, judging page).

| When | What happens |
|---|---|
| Fri 16 Oct, afternoon and evening | Doors open, talks, track intros, visit and Q&A with the Lord Mayor of Southampton |
| **Fri 16 Oct, 20:00** | **Hacking opens** |
| Sat 17 Oct | Hacking all day. Venue open Fri and Sat nights, can stay overnight |
| **Sun 18 Oct, 13:00** | **Hacking stops, submissions lock. No extensions** |

## Event-wide rules (all tracks)

- Teams of four.
- Hacking runs Fri 20:00 to Sun 13:00.
- You own what you build.
- Build during the event. Repo created after hacking opens.
- Open-source libraries, templates and pre-trained models allowed. Your own earlier projects are not.
- README discloses what was AI-generated, what existed before the event and who helped.
- Every number shows its source and collection date. Cached data never shown as live, synthetic never as real.
- No secrets in the repo.

## Deliverables

On the team page before 13:00 Sunday. Full detail in [judging.md](judging.md#what-to-submit).

1. YouTube demo video, 1:00 to 3:00, showing the real product.
2. Summary, up to 150 words.
3. Public GitHub repo link.
4. Optional: live link or run instructions.
